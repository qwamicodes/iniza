# Superseded MoveMyMac Wireframe Packs

> **Historical concept only.** These desktop wireframes predate the Iniza CLI-first revision. They are retained as product-design research and are not a current functional or implementation contract. The current interface specifications are [../FDS.md](../FDS.md) and [../CLI_SPEC.md](../CLI_SPEC.md).

Open [index.html](index.html) to browse the four functional wireframe packs:

- **Pack A — Start and permissions:** welcome, intent, and progressive coverage
- **Pack B — Prepare the bundle:** discovery, review, recovery, storage, and readiness
- **Pack C — Restore and verify:** unlock, plan, conflicts, progress, and verification
- **Pack D — Manage and maintain:** history, connectors, security, recipes, and licensing

The gallery includes pack filters and a light/dark application appearance toggle. These are functional wireframes, not final brand or high-fidelity visual designs.

The historical screen behavior was previously described by an older FDS and is no longer normative.
